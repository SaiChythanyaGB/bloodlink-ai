# Limitations and responsible use
- Educational prototype only; not clinically validated.
- Simplified red blood cell ABO/Rh compatibility only. Real decisions require component-specific protocols, antibody screening, crossmatching, and clinical review.
- Donor eligibility is manually entered and not medically inferred.
- No automatic donor contact.
- Straight-line distances do not represent travel time.
- Synthetic data is for software demonstration only.
- Local SQLite and no authentication are unsuitable for production deployment.
